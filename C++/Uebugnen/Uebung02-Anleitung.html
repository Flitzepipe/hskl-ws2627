Übung 01

Visual Studio Code einrichten 🧰 Der nächste Schritt: vom einfachen Editor zur Entwicklungsumgebung

Bisher haben Sie im einfachen Editor (Notepad & Co.) geschrieben. Der nächste Schritt: Visual Studio Code (kurz: VS Code). Er zeigt C++-Code bunt an (Schlüsselwörter, Texte, Kommentare in verschiedenen Farben), markiert Fehler bereits beim Tippen, rückt automatisch ein und kann Ihren Code per Tastendruck übersetzen. Ab jetzt ist VS Code die Arbeitsumgebung dieser Vorlesung – und mit dem Basis-Set ist sie in wenigen Minuten eingerichtet.

🤖 Kurz notiert – Copilot: VS Code bietet beim ersten Start die optionale Copilot-Anmeldung an. Für jetzt: einfach überspringen (nicht anmelden). Copilot ist als Schritt 2 Thema der Vorlesung.

1️⃣ VS Code installieren

🪟 Windows
Eingabeaufforderung — □ ✕
C:\Users\Anna> winget install Microsoft.VisualStudioCode C:\Users\Anna> code --version 1.95.3

oder: Grafisch von code.visualstudio.com → „Download for Windows“ → Installer durchklicken.

🍎 macOS
anna@MacBook-Pro — -zsh — 80×24
anna@MacBook-Pro ~ % brew install --cask visual-studio-code anna@MacBook-Pro ~ % code --version 1.95.3

oder: Grafisch von code.visualstudio.com → dmg-Datei öffnen → VS Code in den Programmordner ziehen.

🐧 Linux (Ubuntu)
anna@ubuntu: ~ — □ ✕
anna@ubuntu:~$ sudo snap install code --classic anna@ubuntu:~$ code --version 1.95.3

oder über code.visualstudio.com (deb-Paket).

✅ So sieht Erfolg aus: code --version druckt eine Versionsnummer. (Funktioniert der Befehl code nicht, obwohl VS Code installiert ist: Windows/macOS einmal abmelden und neu anmelden bzw. VS Code einmal öffnen und mit Strg+Shift+P → „Shell Command: Install ‚code‘ command in PATH“ bestätigen.)

2️⃣ Das C++-Basis-Set für VS Code – genau eine Erweiterung

Für unser Hello-World-Setup brauchen Sie nur die eine offizielle Erweiterung – kein „Extension Pack“, keine Themes:

Erweiterung: „C/C++“ (von Microsoft) – Marketplace-ID: ms-vscode.cpptools
📖 Was sie bringt: farbige Code-Darstellung (Syntax-Highlighting), automatische Vervollständigung beim Tippen (IntelliSense), Markierung unbekannter Befehle, und die tasks.json-Logik, mit der VS Code weiß, wie Ihr Code zu übersetzen ist.
  1. VS Code starten
  2. Links in der Seitenleiste auf das Erweiterungen-Symbol klicken (die vier Quadrate; Tastenkürzel Strg+Shift+X)
  3. Im Suchfeld C/C++ eintippen
  4. Den Eintrag „C/C++“ mit dem blauen Microsoft-Logo und „ms-vscode.cpptools“ wählen → Install klicken
  5. Nicht nötig fürs Erste: „C/C++ Extension Pack“, „C/C++ DevTools“ – alles Weitere kommt später in der Vorlesung
✅ So sieht Erfolg aus: In der Erweiterungs-Liste steht bei „C/C++“ nun ein Zahnrad statt eines Install-Buttons. Mehr brauchen wir nicht – der Compiler selbst (g++) wurde bereits in Teil a installiert, die Erweiterung ist nur der „Dolmetscher“ zwischen VS Code und g++.

3️⃣ Hello World in VS Code – mit der entscheidenden tasks.json

1

Projektordner in VS Code öffnen

VS Code denkt in Ordnern („Workspaces“). Öffnen Sie Ihren Übungsordner:

🪟 Windows
Eingabeaufforderung — □ ✕
C:\Users\Anna> cd progcpp-ubungen C:\Users\Anna\progcpp-ubungen> code .
🍎 macOS
anna@MacBook-Pro — -zsh — 80×24
anna@MacBook-Pro ~ % cd progcpp-ubungen anna@MacBook-Pro progcpp-ubungen % code .
🐧 Linux
anna@ubuntu: ~ — □ ✕
anna@ubuntu:~$ cd progcpp-ubungen anna@ubuntu:~/progcpp-ubungen$ code .

VS Code öffnet sich mit Ihrem Ordner. Falls ein Dialog fragt „Do you trust the authors?“ → „Yes, I trust“ (es ist Ihr eigener Ordner).

✅ So sieht Erfolg aus: Links sehen Sie die Dateien Ihres Übungsordners (z. B. hello.cpp von vorhin). Unten gibt es ein eingebautes Terminal – das ist Ihr bekanntes cmd/Terminal, nur hier einklappbar.
2

Datei anlegen und Code schreiben

In der linken Seitenleiste (Explorer): Icon „Neue Datei“ → Name hallo.cpp (oder Sie öffnen Ihre bestehende hello.cpp per Klick). Tippen Sie:

1#include <iostream> 2 3int main() { 4 std::cout << "Hello, VS Code!" << std::endl; 5 return 0; 6}

Speichern: Strg+S (macOS: Cmd+S). Ab jetzt ist der Code bunt – violette Schlüsselwörter, blaue Texte, graue Kommentare: Das ist das Syntax-Highlighting der C/C++-Erweiterung.

✅ So sieht Erfolg aus: Beim Tippen von std:: schlägt VS Code automatisch sinnvolle Ergänzungen vor (IntelliSense) – mit Tab übernehmen, mit Esc ignorieren.
3

Erster Start über den ▶-Button – VS Code baut die tasks.json selbst

Öffnen Sie hallo.cpp, sodass es die aktive Datei ist, und klicken Sie oben rechts den ▶-Pfeil (Play-Button). Im Dropdown wählen Sie:

„C/C++: g++ build and run active file“ bzw. „C/C++: g++.exe build and run active file“ (Windows) – je nach System steht da clang++ (macOS), das ist equally richtig.

VS Code übersetzt Ihr Programm und startet es im eingebauten Terminal. Und: Beim ersten Mal hat VS Code still im Hintergrund die Datei .vscode/tasks.json angelegt – die „Rezept-Kartei“, wie Ihr Projekt zu übersetzen ist.

✅ So sieht Erfolg aus: Im Terminal unten erscheint Hello, VS Code!. Und im Explorer liegt jetzt der Ordner .vscode mit der Datei tasks.json.
4

Die tasks.json verstehen – und anpassen

Öffnen Sie im Explorer den Ordner .vscode → Doppelklick auf tasks.json. Dort steht (je nach Plattform minimal anders) sinngemäß:

{ "version": "2.0.0", "tasks": [ { "type": "cppbuild", "label": "C/C++: g++ build active file", "command": "g++", "args": [ "-fdiagnostics-color=always", "${file}", "-o", "${fileDirname}/${fileBasenameNoExtension}" ], "options": { "cwd": "${fileDirname}" }, "problemMatcher": ["$gcc"], "group": { "kind": "build", "isDefault": true } } ] }
📖 Zeile für Zeile – was hier steht:
  • "command": "g++" – welches Programm VS Code aufruft: Ihren Compiler g++ (macOS zeigt hier clang++)
  • "args" – mit welchen Argumenten: übersetze die aktive Datei (${file}) und nenne das Ergebnis wie die Datei ohne Endung (-o ${fileDirname}/${fileBasenameNoExtension}) → aus hallo.cpp wird hallo bzw. hallo.exe
  • "label" – der Anzeigename des Rezepts, z. B. im Play-Button-Menü
  • "problemMatcher": ["$gcc"] – liest g++-Fehlermeldungen und markiert die Stellen direkt im Editor rot – Fehlerzeilen werden klickbar!
  • "group": { "isDefault": true } – macht dieses Rezept zum Standard: Ab jetzt genügt Strg+Shift+B

Praktischer Feinschliff (optional): Wer möchte, hängt in args noch "-Wall" und "-std=c++17" ein – dann warnt g++ gründlicher und nutzt den modernen Sprachstandard. Danach Datei speichern.

✅ So sieht Erfolg aus: Ab jetzt genügt Strg+Shift+B (= Übersetzen), dann im eingebauten Terminal ./hallo bzw. hallo.exe tippen (= Starten). Der Play-Button macht beides in einem Rutsch.
5

Fehler provozieren – der VS-Code-Vorteil

Wiederholen Sie Teil c aus Übung 01 (Semikolon löschen), aber diesmal in VS Code: Nach Strg+Shift+B erscheint die Fehlermeldung nicht nur im Terminal – die betroffene Zeile wird rot im Editor markiert, und in der Registerkarte „Problems“ (Strg+Shift+M) klicken Sie direkt zur Stelle. Genau dafür lohnt sich die problemMatcher-Zeile in der tasks.json.

✅ So sieht Erfolg aus: Rote Wellenlinie unter dem Code, Eintrag in der Problems-Liste, Klick springt zur Stelle. Semikolon zurück → speichern → neu übersetzen → Fehler verschwunden.
